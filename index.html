OPTIONS

Éléments : choisis un outil puis glisse pour placer · Plateforme / Piques : largeur · Mur / Eau / Boue : rectangle (peuvent creuser le sol) · Ronces : glisse le long d’un mur · Passage : pose une porte puis relie-la à une autre zone · Départ : point de départ du monde · Creuser / Vide : glisse sur le sol · Mobs : sous-onglets PNJ et Ennemis, choisis puis clique pour placer · PNJ → Écrire un dialogue (ou outil Dialogue) : clique un PNJ déjà placé pour écrire ses répliques, une par ligne · ← → ↑ ↓, Vue ou clic droit maintenu pour défiler · « Hauteur » agrandit la zone vers le haut · « Fonds » : sous-onglets Premier plan (buissons, herbe, feuilles), Deuxième plan (arbres, oiseaux) et Fond (ciel, couleur du sol) ; Décors libres pour déplacer, tourner et redimensionner les décors · Laine : glisse ou clique pour poser la liane-laine (taille du personnage) sur le sol, une plateforme ou un mur comme les ronces ; attrape sa boule de coton avec la liane (Q) pour te tracter vers elle, saute pour lâcher · Feuilles : choisis une feuille puis clique pour la poser comme décor ; Gomme pour la retirer · Décors : choisis un plan (Deuxième ou Premier) puis un élément, clique pour le poser ; mode Déplacer pour glisser un décor posé, l’agrandir ou le rapetisser (Taille), le tourner (Rotation) ; Miroir, Réinitialiser, Supprimer ; Gomme pour le retirer · Fenêtres : tire un coin pour redimensionner la fenêtre à ta guise, tout le contenu et le texte suivent la taille, double-clic sur un coin pour revenir à la taille d’origine
